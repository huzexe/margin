    Binary Search

    Lecture 4 · Searching algorithms

    What is binary search?

    Binary search is a method for finding a value in a sorted array. Instead of checking every element one by one, it looks at the middle element and uses the sorted order to discard half of the remaining elements at each step.

    Definition

    Search space: the part of the array that may still contain the target and has not been ruled out yet.

    How it works

    1. Set low to the first index and high to the last.
    2. Compare the target with the middle element.
    3. If the target is smaller, continue in the left half; if larger, in the right half.
    4. Stop when the target is found or the search space is empty.

    Example

    Example

    Searching for 23 in [4, 9, 15, 23, 42, 57]: the middle is 15, 23 is larger, so the left half is discarded. The next middle is 42, 23 is smaller, then 23 is found.

    def binary_search(arr, target):
    low, high = 0, len(arr) - 1
    while low <= high:
        mid = (low + high) // 2
        if arr[mid] == target:
            return mid
        if arr[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1

    Time complexity

    Formula

    $$T(n) = T\!\left(\tfrac{n}{2}\right) + O(1) \;\Rightarrow\; T(n) = O(\log n)$$

    MethodNeeds sorted dataWorst case
    Linear searchNo\(O(n)\)
    Binary searchYes\(O(\log n)\)

    Why not on a linked list?

    A linked list cannot jump straight to its middle element. Reaching the middle means walking through about half the nodes, which takes \(O(n)\) time and removes the advantage of halving.

    Key takeaways

    Key takeaways
    • Works only on sorted data.
    • Each comparison halves the search space.
    • Runs in \(O(\log n)\) time, compared with \(O(n)\) for linear search.
